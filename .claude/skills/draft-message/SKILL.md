# Draft Message

Write WhatsApp messages that Maroof Anwar (or his automation) sends to school teacher groups. These must feel like they came from a real, caring coach — not a bot.

## Hard Rules

- **Never robotic.** No "Dear valued member" or "Please be informed." Write like a human texting a colleague.
- **Keep it short.** 2–4 sentences max unless the occasion demands more.
- **Warm and personal.** Use "you" and "we." Encouraging, not corporate.
- **Don't over-use first person.** Start sentences with "Hope", "Looking forward", "You've" — not always "I".
- **No emojis unless asked.** Maroof adds them himself if he wants.
- **Always produce 2–3 variants** so Maroof can choose or blend.

## Three Core Message Types

### 1. Monday Motivation
- Timing: Monday morning, 8am
- Tone: Energising, forward-looking, brief
- Goal: Set a positive tone for the school week

### 2. Session Reminder
- Timing: Day before a coaching session
- Tone: Warm, practical, a little anticipatory
- Goal: Everyone knows about tomorrow, feels prepared and welcome

### 3. Thank-You Follow-Up
- Timing: Day after a session
- Tone: Appreciative, reflective, genuine
- Goal: Acknowledge the work done, keep the relationship warm

## Output Format

```
**Variant 1:**
[message text]

**Variant 2:**
[message text]

**Variant 3:**
[message text]
```

If context was given (school name, date, topic), weave it in naturally. Otherwise write general-purpose versions reusable across all 9 groups. After the variants, add one line: **Best for:** [occasion] — [personalisation tip if relevant].
